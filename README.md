# Домашнее задание к работе 4

## Условие задачи (Вариант 11)

В умном коворкинге два сканера: по лицу (A) и по карте (B). Система открывает дверь, если ровно один из сканеров вернул четный код доступа (такие коды выдаются временным посетителям). Запишите условие открытия двери.

* * *

## 1. Алгоритм и блок-схема

### Алгоритм

1. Запросить у пользователя код сканера по лицу `a` и код сканера по карте `b`.
2. Вычислить логическое условие открытия без использования условного оператора `if`:  
   `condition = (a % 2 == 0) != (b % 2 == 0)`.  
   Выражение равно 1, если чётность кодов различается, то есть ровно один код четный.
3. Вывести результат (1 — дверь открыта; 0 — дверь закрыта).
4. Завершить программу.
